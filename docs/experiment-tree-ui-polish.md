# 实验树 · 界面设计 / 按钮排版 / 配色 优化规格

> 基于对当前三视图（画布 / 折线图 / 变量收益）+ 深浅主题的实测 review。功能已完整、配色体系基本到位（中性节点、indigo 选中、绿/红 delta、ROI 视图齐全）。本规格只做**界面设计、按钮排版、配色**的打磨，**纯前端**：`web/static/app.js`(`ExperimentTree` 模板) + `web/static/style.css`(`.exp-*`)，不动后端/接口/数据。
> 实测确认的结构：工具栏只有两个容器 `.exp-title-block`(返回) 和 `.exp-toolbar-actions`，后者把 `标记优化关系 / 画布 / 折线图 / 变量收益 / 刷新`(+画布视图的`自动整理`)**全平铺在一排**；视图 tab 已有 `.exp-view-tab` 类但未成组。

---

## A. 按钮排版（P0，最该改）

### A1 视图切换做成独立「分段控件」，与操作按钮分离
现状：视图 tab（画布/折线图/变量收益）和操作（标记优化关系/自动整理/刷新）混在同一排，主次不分、来回扫视。
- [ ] 把三个 `.exp-view-tab` 包进一个**分段控件容器**（单一圆角边框、内部分隔），作为一个视觉整体。
- [ ] 工具栏分三区，左→右：**① 标题/返回** ② **视图分段控件**（画布｜折线图｜变量收益） ③ **操作区**（`标记优化关系` 主按钮 + `自动整理`/`刷新` 次级）。
- [ ] `自动整理` 仅画布视图出现（现状已是），`刷新` 常驻；二者可用 icon 按钮（`ti-refresh` / 整理图标）省宽度。

### A2 避免两个 indigo 实心按钮抢视线
现状：`标记优化关系`(主CTA, indigo 实心) 与 **激活态视图 tab**(也 indigo 实心) 同排都重色，互相竞争。
- [ ] 激活态 tab 改为**轻 indigo**（浅底 `--purple-bg` + indigo 文字，或下划线/底色高亮），**整排只保留 `标记优化关系` 一个强 indigo 实心**。
- [ ] 非激活 tab 用 `--text2`，hover 才加深。

### A3 二级（视图专属）工具栏统一规范
折线图/变量收益各有第二排控件（主指标下拉、目标值、按变量/按具体变更、总收益/平均收益）。
- [ ] 固定放在**主工具栏下方的二级行**，左对齐；每个控件统一「小标签 + 控件」样式。
- [ ] 同类切换（按变量/按具体变更、总收益/平均收益）也用**分段控件**，与 A1 风格一致。
- [ ] 画布视图无二级行时不留空白占位。

## B. 界面设计 / 信息架构（P1）

### B1 右侧「项目」面板按视图收敛
现状：项目摘要面板在三视图都常显；在变量收益视图里它和顶部摘要卡（变量种类/可评估关系…）信息重复。
- [ ] 变量收益 / 折线图视图下，右面板**默认折叠**（保留 `›` 展开），或只留"未连接任务"快捷区；避免与视图内摘要重复。
- [ ] 画布视图保持现状（选中节点/边时展示详情面板）。

### B2 变量收益：无单独归因数据时别显示空条形图
现状：当项目只有"组合变更边"时，条形图所有变量都是 `0.00 ms` 空条，像坏了。
- [ ] isolated 数据为空时，**用提示替代空条形图**："当前只有组合变更，暂无法单独归因；做单变量实验后这里会显示各变量收益"。
- [ ] 有 isolated 数据才渲染条形图。

### B3 画布边标签：变更项用 mini chip，别堆原始文本
现状：边标签把变更项渲染成 `- combo: False → True` / `- triton fuson` 多行左对齐文本 + 一个 delta 芯片，像粘贴的原文。
- [ ] 变更项渲染成**一排小 chip**（`name: a→b`），与描述文本分区；标签整体更紧凑。
- [ ] 描述长文截断（`line-clamp`），完整内容进边详情面板。

### B4 多版本指标表 / ROI 表密度
- [ ] 表格 `0.00 ms / 0.0%` 两行堆叠可读但偏挤：主值正常字号、次值（%）小一号且 `--text3`，建立层级。
- [ ] 表头列可排序的给排序箭头视觉反馈；当前默认排序列高亮。

## C. 配色（P2，体系已好，只做微调）

- [ ] **目标线标签改中性**：折线图"目标 43.00 ms"现为**红色**框；红=退化/坏，而目标是参考线，语义冲突。改 indigo/中性灰（`--purple` 或 `--text3`），避免和"退化红"混淆。
- [ ] **激活态 indigo 收敛**：见 A2，避免主 CTA 与激活 tab 同强度 indigo。
- [ ] **delta / 收益色统一**：画布 delta 芯片、ROI 条形/数值、折线图，绿一律 `--green`、红一律 `--red`，确认三处同源（不要某处又冒出 emerald/rose 变体）。
- [ ] **分段控件激活底色**：用 `--purple-bg`（与侧边栏 qv 选中、app 体系一致），保持克制。
- [ ] 深浅主题复核：二级工具栏、分段控件、ROI 表格/条形、目标线标签在两主题下对比度均达标（用 CSS 变量，勿写死）。
