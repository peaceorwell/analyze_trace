使用指南

1. 上传与对比

  • 首页提供 单个、两个、多个 三种上传模式；常用格式包括 .json、.json.gz、.gz、.json.zip、.zip、.tar.gz、.tgz
  • 上传时选择项目和别名即可；如果只想看指定 step，先完成原始分析，再用任务右上角 指定 Step 重分析 生成新条目
  • 两个 模式会直接生成 A/B 对比任务；多个 模式会逐个分析每个 trace；已有历史任务可在项目右侧 项目管理 菜单中选择 新建对比

2. 结果优先看什么

  • 性能总览 是默认页：先看设备计算耗时、Top 回退/改善、占比和 Delta 图；通信类 kernel/op 默认不计入，且该口径不等同于端到端耗时
  • AI 分析 适合快速得到 Markdown 报告；控制台 适合核对脚本原始摘要和生成文件
  • Kernel 类型、所有 Kernel、Triton、ATen Ops 用于下钻；图表和类型行可点击跳到相关表格
  • 类型对比 会同时展示耗时 delta 和调用数 delta；未知 Triton family 统一显示为 triton_other
  • CSV 表格支持搜索、筛选、排序、列显隐和分页；页面可安全显示前 2,000 行，并支持下载当前页或导出全部筛选结果
  • 列宽会按内容自适应，短数值列默认更紧凑；数字列按字段名和列内容识别，并与表头字段一起居中显示

3. 实验树

  • 项目侧边栏带树形标记时，可直接打开该项目的实验树；在树里用 标记优化关系 连接父子实验
  • 节点卡片以 Compute time 为主指标，主指标行的 delta 仅显示箭头百分比；关系标签适合填写这次修改的正文和变量变更
  • 优化判定优先看 Compute time；节点和关系标签会用配色快速区分性能最优、正优化和负优化
  • 如果两端 step 数或单步口径不一致，右侧详情会提示“跨度对比仅供参考”，此时建议先统一 step 再判断收益
  • 画布支持拖拽、缩放、自动整理和右侧面板折叠；自动整理会按内容收敛节点尺寸，节点与关系标签都可以单独调整尺寸

4. AI 分析

  • 服务端开启 Claude Code 后会出现 AI 分析 页签；开始时可填写可选补充 Prompt
  • 系统会先做环境诊断，诊断通过才调用单 trace 或对比 trace skill 生成报告
  • 报告支持 Markdown 渲染、复制、下载和历史版本切换；页面会显示生成时间、触发人、模型和耗时
  • AI 分析耗时较长，可以切走页面；完成后会通过浏览器通知或邮件提醒

5. 历史、项目和文件

  • 左侧历史按项目分组，支持搜索、分页、置顶、多选、批量移动、删除任务和删除原始文件
  • 打开任务或实验树时，侧栏只高亮当前条目，不会改变项目内原有排序
  • 登录模式下有个人项目和共享项目；共享项目便于团队查看和复用 trace 做对比
  • 删除任务会一起清理 trace、压缩副本、结果 CSV、AI 产物和 Triton 代码；删除项目会先进回收站
  • Perfetto 按钮可打开 trace；下载默认提供压缩后的 .json.gz

6. 灵感社区

  • 右上角或首页卡片进入 灵感社区，用于提建议、贴问题和交流使用经验
  • 帖子和回复支持图片、Markdown、Emoji、表情反应、作者编辑和 @英文名 候选
  • 新帖子或回复会邮件通知管理员；被 @ 的同事也会收到直达帖子/回复的链接
  • 管理员可删除帖子/回复，并使用邮件诊断检查通知链路
