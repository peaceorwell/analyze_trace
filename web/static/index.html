使用指南

1. 提交分析

  • 在主区域上传区拖拽或点击上传一个或多个 .json / .json.gz 文件（PyTorch Profiler 导出的 Chrome Trace 格式）
  • 选择所属项目（可选），填写别名（可选）
  • 勾选 Triton CSV 详情：输出逐 step 的 Triton kernel 详情表格
  • 勾选 Triton 代码保存：保存每个 Triton kernel 的生成源码，可在结果中查看和执行
  • 点击"提交分析"，后台异步处理，实时显示上传进度和运行状态

2. 查看结果

  • 控制台：原始文本输出，含 Per-Step 摘要、Top 10 热点 kernel、Kernel 类型分布
  • 图表：Kernel 类型耗时柱状图（横向）和占比饼图，collective 类型不计入 compute 分析
  • CSV 表格：按页加载，支持搜索、列排序、列宽拖拽、列显隐、超长内容截断并 hover 显示全文
  • 会按任务记住上次打开的结果页签，以及各表格的搜索、排序、列宽、列筛选和列显隐
  • 下载当前页 CSV：表格右上角可下载当前分页中的 CSV 内容

3. 侧栏与历史管理

  • 左侧侧栏可拖拽调整宽度，点击箭头按钮可折叠/展开
  • 侧栏包含两个标签页：历史（单文件任务）和对比（对比任务）
  • 历史按项目分组显示，点击项目标题可折叠/展开该组
  • 顶部可选择项目过滤器，筛选特定项目的历史记录
  • 支持按任务、文件或项目搜索历史记录
  • 展开项目后按需加载任务，较大的项目可继续点击“加载更多”
  • 进入多选后，可批量移动任务、删除任务或删除原始文件
  • 支持分页浏览，底部有分页控件
  • 点击任务行可查看分析详情

4. 项目管理

  • 点击"+ 新建项目"创建项目，用于归类管理分析任务
  • 支持重命名项目、移动任务到其他项目
  • 删除项目：项目及其下的所有任务保存到回收站（10 天内可恢复）
  • 找回项目：在"找回项目"中可恢复近 10 天内删除的项目，任务会一起恢复
  • 超过 10 天的已删除项目会显示"已过期"标签，只能永久删除

5. 历史对比

  • 在侧栏"对比"标签页选择两个已完成的单文件任务
  • 候选任务支持独立搜索和分页，已选任务会固定显示在列表上方
  • 可选填别名和所属项目
  • 点击"发起对比"，系统直接复用已有数据，无需重新上传文件
  • 对比结果页会显示 A/B 来源任务，可跳回源任务，也可交换 A/B 重新发起对比
  • 对比结果含 Kernel 对比、Triton 对比、Aten 对比、类型对比、CNCL 对比等多个维度
  • 源文件被删除后对应任务将标记"已删除"标签，无法参与对比

6. 文件操作

  • 下载：可下载原始 trace 文件（受服务器 --no-download 参数控制）
  • Perfetto：点击"Perfetto ↗"按钮在 Perfetto UI 中打开 trace 文件进行深入分析
  • 删除文件：删除原始 trace 文件后，对应任务会标记"已删除"，无法再参与对比
  • 删除前会提示受影响的历史对比数量，便于确认清理范围

7. 运行 Triton 代码

  • 在 Triton 或 Triton Step N 表格中，每行有"运行"按钮
  • 点击运行后会执行对应的 Triton kernel 代码，弹出执行结果
  • 效率值会显示在行内（单位 GB/s），旁边有 ↻ 按钮可重新运行
  • 清除 Cache：在 Triton Step N 表格右上角有"清除 Cache"按钮，可清除 /tmp/torchinductor_* 缓存目录，重新运行以获得准确性能数据

注意：此功能依赖 MLU（寒武纪）硬件环境。需要已安装 torch_mlu 驱动并有物理 MLU 加速卡。 在非 MLU 环境下执行会报 ImportError，这是正常现象，不代表程序出错。

8. 其他功能

  • 深色/浅色模式：右上角切换按钮，自动记忆偏好
  • 存储管理：查看原始 trace / 结果文件占用，并集中清理原始文件
  • 侧栏可拖拽调整宽度，可折叠以扩大主区域可视范围
  • 点击标题栏可返回上传页面
