使用指南

1. 上传与快速对比

  • 首页默认支持 单文件/批量 和 快速对比 两种入口；常用格式包括 .json、.json.gz、.gz、.json.zip、.zip、.tar.gz、.tgz
  • 上传时选择项目和别名即可；如果只想看指定 step，先完成原始分析，再用任务右上角 指定 Step 重分析 生成新条目
  • 两个新 trace 直接用 快速对比；已有历史任务则在左侧 对比 页签选择 A/B

2. 结果优先看什么

  • 性能总览 是默认页：先看总耗时、Top 回退/改善、占比和 Delta 图，通信类 kernel/op 默认不计入计算统计
  • AI 分析 适合快速得到 Markdown 报告；控制台 适合核对脚本原始摘要和生成文件
  • Kernel 类型、所有 Kernel、Triton、ATen Ops、CNCL Ops 用于下钻；图表和类型行可点击跳到相关表格
  • CSV 表格支持搜索、筛选、排序、列显隐、分页大小调整、显示全部和下载当前页

3. AI 分析

  • 服务端开启 Claude Code 后会出现 AI 分析 页签；开始时可填写可选补充 Prompt
  • 系统会先做环境诊断，诊断通过才调用单 trace 或对比 trace skill 生成报告
  • 报告支持 Markdown 渲染、复制、下载和历史版本切换；页面会显示生成时间、触发人、模型和耗时
  • AI 分析耗时较长，可以切走页面；完成后会通过浏览器通知或邮件提醒

4. 历史、项目和文件

  • 左侧历史按项目分组，支持搜索、分页、置顶、多选、批量移动、删除任务和删除原始文件
  • 登录模式下有个人项目和共享项目；共享项目便于团队查看和复用 trace 做对比
  • 删除任务会一起清理 trace、压缩副本、结果 CSV、AI 产物和 Triton 代码；删除项目会先进回收站
  • Perfetto 按钮可打开 trace；下载默认提供压缩后的 .json.gz

5. 灵感社区

  • 右上角或首页卡片进入 灵感社区，用于提建议、贴问题和交流使用经验
  • 帖子和回复支持图片、Markdown、Emoji、表情反应、作者编辑和 @英文名 候选
  • 新帖子或回复会邮件通知管理员；被 @ 的同事也会收到直达帖子/回复的链接
  • 管理员可删除帖子/回复，并使用邮件诊断检查通知链路
